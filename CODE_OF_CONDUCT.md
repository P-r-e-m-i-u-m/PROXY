# Code of Conduct

This project is for practical AI infrastructure work. Keep discussions respectful, technical, and useful.

## Expected

- Explain problems clearly.
- Share reproduction steps when reporting bugs.
- Review code with respect.
- Keep security-sensitive details private.

## Not Expected

- Harassment or insults.
- Spam.
- Requests for fake stars, forks, or artificial engagement.
- Sharing secrets, private keys, or private logs.

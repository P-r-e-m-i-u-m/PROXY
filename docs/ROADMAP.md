# Roadmap

## v1.1 - Gateway Hardening

- Add gateway client API-key authentication.
- Add request timeout configuration.
- Add structured JSON logs.
- Add provider retry metadata to logs.

## v1.2 - Reliability

- Add per-provider circuit breaker state.
- Add provider health probes.
- Add retry backoff.
- Add integration tests with mock upstream providers.

## v1.3 - Production Operations

- Add Redis-backed rate limiting.
- Add Docker healthcheck configuration.
- Add example deployment guides.
- Add dashboard-ready metrics documentation.

## Contribution Notes

Roadmap issues should stay small enough to review. A strong issue includes:

- problem
- proposed behavior
- acceptance criteria
- test command
